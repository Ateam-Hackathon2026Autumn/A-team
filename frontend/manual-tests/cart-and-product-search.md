# 商品検索・カートの手動テスト

## 準備

```powershell
cd frontend
npm run dev
```

- ターミナルに表示されたURLを開く。以下のパスはそのURLを基準にする。
- `VITE_USE_MOCK=false` が設定されていないことを確認する。
- `npm run preview` ではモックが無効になるため、今回は使用しない。
- 既定のセッションモックはログイン済み。ログアウト状態に変更済みの場合は、カート追加テスト時に元へ戻す。
- モックは実通信をしないため、Networkタブには表示されない。APIの処理結果はConsoleの `[mock]` ログで確認できる。
- カートの商品・数量は同じタブのsessionStorageに保存する。ブラウザーの「戻る」・URL直接入力・再読み込みでも保持する（同じオリジン・同じタブで確認）。
- 初期状態からテストする場合は、カート上部の「デモカートを初期状態に戻す」を押す。

## 1. 日本語入力の修正確認

PCで `/products` を開く。スマートフォン幅では「絞り込み」を開く。

| 操作 | 期待結果 |
| --- | --- |
| キーワード欄にIMEで `yamamoto` と入力する | `やまもと` と表示され、`ｙあｍあｍおｔお` のように分断されない |
| 変換候補から「山本」を選び、「農園」を続けて入力・変換・確定する | 「山本農園」と入力できる。確定後、りんごとシャインマスカットの2件になる |
| 変換中にSpace・矢印キーで候補を変更する | 入力が途中で戻ったり、フォーカスが外れたりしない |
| Backspaceで削除、途中へカーソルを移動して修正する | 入力したとおりに編集できる |
| 「山本農園」をコピー＆ペーストする | 2件になる |
| 半角英数字を連続入力する | 文字が欠けたり巻き戻ったりしない |
| 条件をリセットする | 入力欄も空になり、8件へ戻る |
| `/products?q=山本農園` を直接開く | 入力欄に「山本農園」が入り、2件になる |

変換中は検索URLと検索結果を更新せず、変換確定後に反映する。
可能であればChromeとEdgeの両方で確認する。

## 2. カートの初期表示

`/cart` を開き、「デモカートを初期状態に戻す」を押す。

| 確認箇所 | 期待結果 |
| --- | --- |
| 商品 | 安曇野ふじ×1、あじの開き干し×2 |
| 合計点数 | 3点 |
| 生産者ごとの表示 | 山本農園と海風水産に分かれる |
| 商品小計 | 4,800円と6,400円 |
| 商品合計 | 11,200円（税込・送料別） |
| 配送情報 | 常温・冷凍の区別、発送目安、参考送料が表示される |
| 送料 | 「注文時に確定」と表示され、商品合計へ勝手に加算されない |

## 3. 数量変更・削除・空カート

以下は続けて操作する。

| 操作 | 期待結果 |
| --- | --- |
| りんごの「＋」を1回押す | りんご2点、小計9,600円、全体4点、合計16,000円 |
| りんごの「−」を1回押す | 初期数量と合計11,200円に戻る |
| 数量1のりんごを確認 | 「−」は無効で、0点にならない |
| りんごの数量をプルダウンで10へ変更 | 小計48,000円、全体12点、合計54,400円。「＋」が無効になる |
| 「買い物を続ける」→ブラウザーの「戻る」でカートへ戻る | 変更後の数量が保たれる |
| 同じタブのアドレスバーから `/cart` を再度開く | りんご10点、合計54,400円が保たれる |
| ブラウザーを再読み込みする | りんご10点、合計54,400円が保たれる |
| あじの開き干しを削除 | 海風水産の表示が消え、りんご10点、合計48,000円になる |
| りんごも削除 | 「カートは空です」と「商品を探す」が表示される。購入手続きへ進めない |
| 空カートを再読み込みする | 初期商品が復活せず、空カートのままになる |
| 空カートから「商品を探す」を押す | 商品一覧へ遷移する |

※ カートへ戻る際に新たに商品を追加すると、その数量も合算される。

## 4. 商品詳細から追加・在庫不足

1. `/cart` の「デモカートを初期状態に戻す」を押す。
2. 「買い物を続ける」→シャインマスカットの商品詳細を開く。
3. 数量2で追加し、完了案内の「カートを見る」を押す。
4. 山本農園の中にりんごとシャインマスカットが表示され、全体5点・商品合計22,000円になることを確認する。
5. シャインマスカットの数量を3へ変更する。全体6点・合計27,400円になる。
6. シャインマスカットの数量をプルダウンで4へ変更する。
7. 在庫不足のエラーが表示され、数量は3・合計27,400円のままであることを確認する。
8. 数量を1へ変更し、エラーが解消され、全体4点・合計16,600円になることを確認する。
9. 更新中に他の数量ボタンや削除を連打しても、二重更新されないことを確認する。

## 5. 画面遷移と表示

- 商品名・画像から、該当する商品詳細へ移動できる。
- 生産者名から、該当する生産者ページへ移動できる。
- 「購入手続きへ」で `/checkout` へ移動できる。現状は見出しのみの準備中画面であり、注文・決済は実行しない。
- カート上にも購入手続き画面が準備中である旨が表示される。
- 375px程度のスマートフォン幅で横スクロールが出ず、数量・削除・合計を操作できる。
- PC幅では商品一覧と注文金額欄が左右に配置される。
- Tabキーで数量・削除・リンクへ移動でき、フォーカス枠が見える。

## 6. エラー表示（任意）

コードを一時変更するテスト。終了後は必ず元へ戻す。
カートを初期化する場合は「デモカートを初期状態に戻す」を使用する。

| 一時変更 | 操作と期待結果 |
| --- | --- |
| `get_api_v1_cart.tsx` の `cart` 定義に `status: 500` を指定 | `/cart` で取得失敗と「再試行」が表示される。成功扱いにならない。指定を外して再確認する |
| `patch_api_v1_cart_items_itemId.tsx` の `status` を409へ変更 | 数量変更でエラーが表示され、最新のカートを取得する。金額は更新されない |
| 同じファイルの `status` を412へ変更 | カート変更の案内が表示され、最新のカートを取得する |
| `delete_api_v1_cart_items_itemId.tsx` の `status` を500へ変更 | 削除でエラーが表示され、商品が消えない |
| `get_api_v1_products_productId.tsx` の `productDetail` 定義に `status: 500` を指定 | カートの補足情報取得失敗が案内される。商品名・数量・金額・削除操作は利用できる |

商品取得失敗テストでは、商品詳細ページも取得エラーになる。
